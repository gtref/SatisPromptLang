The Evolution of HTML

  • 1991 – HTML 1.0 released by Tim Berners-Lee.
  • 1995 – HTML 2.0 standardised (forms, tables).
  • 1997 – HTML 3.2 added applets, text flow.
  • 1999 – HTML 4.01 introduced CSS support and better accessibility.
  • 2004 – XHTML 1.0 (XML‑based HTML).
  • 2014 – HTML5 became a W3C Recommendation, adding multimedia, canvas, and new semantic elements.
  • 2023‑2024 – Ongoing updates (custom elements, new APIs, improved accessibility).

HTML continues to evolve, making the web richer and more interactive while staying backward compatible.

Learn HTML Basics

HTML (HyperText Markup Language) is the foundation of every web page. Below are the core concepts you should know.

1. Document Structure

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>My First Page</title>
  </head>
  <body>
    <!-- Page content goes here -->
  </body>
</html>

2. Common Elements

  • <h1>…</h1> – Headings (h1‑h6)
  • <p>…</p> – Paragraphs
  • <a href="url">…</a> – Links
  • <img src="image.jpg" alt="description"> – Images
  • <ul>, <ol>, <li> – Lists
  • <section>, <article>, <nav>, <header>, <footer> – Semantic containers

3. Forms

<form action="#" method="post">
  <label for="name">Name:</label>
  <input type="text" id="name" name="name">
  <button type="submit">Submit</button>
</form>
