A simple music player for a personal music library.

Suggest any other useful options for a personal music player.

Keep playback controls accessible and show the current track.

Options

Autoplay
false
Initial Volume
0.8
Repeat
none
Shuffle
false
Supported Formats
[mp3, aac, wav]

Actions

  • Play — Start or resume the selected track.
  • Pause — Pause playback without losing the current position.
  • Next Track — Move to the next track in the current queue.
  • Previous Track — Move to the previous track in the current queue.
  • Seek — Move playback to a requested position in the current track.
  • Set Volume — Set the playback volume between zero and one.
  • Toggle Shuffle (behavior to be inferred)
